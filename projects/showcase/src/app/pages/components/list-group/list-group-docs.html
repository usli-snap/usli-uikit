Components / List Group

List Group

A flexible list of items. Project usli-list-group-item children into usli-list-group.

Basic usage

First item Second item (active) Third item (disabled) 
<usli-list-group>
  <usli-list-group-item>First item</usli-list-group-item>
  <usli-list-group-item [active]="true">Second item (active)</usli-list-group-item>
  <usli-list-group-item [disabled]="true">Third item (disabled)</usli-list-group-item>
</usli-list-group>

Linked items

Set href on an item to render it as an interactive link.

Go to A Go to B 
<usli-list-group>
  <usli-list-group-item href="#a">Go to A</usli-list-group-item>
  <usli-list-group-item href="#b">Go to B</usli-list-group-item>
</usli-list-group>

Numbered

First Second Third 
<usli-list-group [numbered]="true">
  <usli-list-group-item>First</usli-list-group-item>
  <usli-list-group-item>Second</usli-list-group-item>
  <usli-list-group-item>Third</usli-list-group-item>
</usli-list-group>

API

usli-list-group

NameTypeDefaultDescription
flush boolean false Removes outer borders/rounding for edge-to-edge lists.
numbered boolean false Renders as an ordered list with numbered markers.
horizontal boolean false Lays items out in a row instead of a column.

usli-list-group-item

NameTypeDefaultDescription
active boolean false Highlights the item as selected.
disabled boolean false Disables interaction.
href string | undefined undefined Renders the item as a link instead of plain text.
variant ButtonVariant | undefined undefined Semantic color variant.
