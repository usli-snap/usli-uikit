Progress

A progress bar. Pure CSS width binding — no JavaScript involved.

Basic usage

<usli-progress [value]="60"></usli-progress>

Striped and animated

<usli-progress [value]="60" [striped]="true"></usli-progress>
<usli-progress [value]="60" [animated]="true"></usli-progress>

Variant and label

<usli-progress [value]="90" variant="success" [showLabel]="true"></usli-progress>

Inputs

NameTypeDefaultDescription
value number required Current value.
max number 100 Value representing 100%.
variant ButtonVariant | undefined undefined Semantic color variant applied to the bar.
striped boolean false Adds diagonal stripes to the bar.
animated boolean false Animates the stripes — implies striped.
label string | undefined undefined Text rendered inside the bar.
showLabel boolean false Shows the percentage inside the bar when no label is set.
