Components / Scrollspy

Scrollspy

Tracks which section is scrolled into view and exposes it as activeId. It doesn't render any nav itself — bind the result to whatever nav you're already using.

Inputs

NameTypeDefaultDescription
targets string[] required Element ids to watch, in document order.
rootMargin string '0px 0px -80% 0px' IntersectionObserver rootMargin — tune where in the viewport a section counts as active.
activeId string | undefined undefined Id of the currently active target. Two-way bindable via [(activeId)].
