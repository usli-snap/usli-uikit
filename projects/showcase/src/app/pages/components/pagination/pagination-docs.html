Pagination

Page navigation with automatic ellipsis collapsing for large page counts. Bind [(page)] to control it from outside.

Basic usage

Current page: {{ page() }}

<usli-pagination [totalPages]="10" [(page)]="page"></usli-pagination>

Many pages

Distant pages collapse behind an ellipsis. First and last pages always stay visible. 

<usli-pagination [totalPages]="50" [page]="25"></usli-pagination>

Inputs

NameTypeDefaultDescription
totalPages number required Total number of pages.
page number 1 Current page (1-indexed). Two-way bindable via [(page)].
siblingCount number 1 Number of pages shown on each side of the current page.
boundaryCount number 1 Number of pages always shown at the start and end.
disabled boolean false Disables all interaction.

Outputs

NameTypeDescription
pageChange OutputEmitterRef<number> Emitted whenever the page changes (paired with the page model).
