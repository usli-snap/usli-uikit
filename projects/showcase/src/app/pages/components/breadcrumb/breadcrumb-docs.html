Breadcrumb

Show the user's location within a hierarchy. The last item always renders as plain text marking the current page, even if it has an href.

Basic usage

Pass an ordered list of items. Every item but the last may have an href. 

<usli-breadcrumb
  [items]="[
    { label: 'Home', href: '/' },
    { label: 'Components', href: '/components' },
    { label: 'Breadcrumb' }
  ]"
/>

Inputs

NameTypeDefaultDescription
items {{ '{' }} label: string; href?: string {{ '}' }}[] required Ordered list of crumbs. The last item is always the current page.

Outputs

NameTypeDescription
itemClick OutputEmitterRef<UsliBreadcrumbItem> Emitted when a non-current, linked crumb is clicked.
