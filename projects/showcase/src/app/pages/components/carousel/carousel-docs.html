Carousel

A slideshow with optional autoplay. Project usli-carousel-item children into usli-carousel. Autoplay pauses on hover and on keyboard focus, per WCAG 2.2.2. No slide transition animation in this version — slides swap instantly.

Basic usage

Slide 1
Slide 2
Slide 3
 
<usli-carousel>
  <usli-carousel-item>...</usli-carousel-item>
  <usli-carousel-item>...</usli-carousel-item>
  <usli-carousel-item>...</usli-carousel-item>
</usli-carousel>

Autoplay

Set interval to autoplay. Hover or focus the carousel to pause it.

A
B
C
 
<usli-carousel [interval]="2000">...</usli-carousel>

API

usli-carousel

NameTypeDefaultDescription
activeIndex number 0 Two-way bindable active slide index.
interval number | undefined 5000 Autoplay interval in ms. Set to undefined or 0 to disable autoplay.
pauseOnHover boolean true Pauses autoplay on hover/focus.
wrap boolean true Wraps from the last slide back to the first (and vice versa).
showIndicators boolean true Shows the dot indicators.
showControls boolean true Shows the prev/next controls.
