Components / Button Group

Button Group

Groups a series of usli-buttons together on a single line or stacked vertically.

Basic usage

Left Middle Right 
<usli-button-group>
  <usli-button variant="secondary">Left</usli-button>
  <usli-button variant="secondary">Middle</usli-button>
  <usli-button variant="secondary">Right</usli-button>
</usli-button-group>

Vertical

Top Middle Bottom 
<usli-button-group [vertical]="true">
  <usli-button variant="secondary">Top</usli-button>
  <usli-button variant="secondary">Middle</usli-button>
  <usli-button variant="secondary">Bottom</usli-button>
</usli-button-group>

Inputs

NameTypeDefaultDescription
vertical boolean false Stacks the buttons vertically instead of horizontally.
size 'small' | 'medium' | 'large' | undefined undefined Sizes every projected button.
ariaLabel string 'Button group' Accessible label for the group.
