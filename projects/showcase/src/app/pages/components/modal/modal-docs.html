Components / Modal

Modal

Built on the native <dialog> element — showModal()/close() and the ::backdrop come from the browser, not a JS modal library. Trigger it with usli-button's Invoker Commands support, or control it programmatically via [(open)].

Basic usage

Give the modal an id and point a button's commandFor/command at it — no click handler needed.

Open modal Are you sure you want to continue?
Cancel Confirm 
<usli-button commandFor="demo-modal" command="show-modal">Open modal</usli-button>

<usli-modal id="demo-modal" title="Confirm action">
  Are you sure you want to continue?
  <div usliModalFooter class="modal-footer">
    <usli-button variant="secondary" commandFor="demo-modal" command="close">Cancel</usli-button>
    <usli-button variant="primary" commandFor="demo-modal" command="close">Confirm</usli-button>
  </div>
</usli-modal>

Static backdrop

Set staticBackdrop to prevent closing via outside click or Escape.

Open static modal This modal only closes via the button below.
Got it 
<usli-modal id="static-modal" title="Read this first" [staticBackdrop]="true">
  This modal only closes via the button below.
</usli-modal>

Inputs

NameTypeDefaultDescription
id string | undefined auto-generated Id of the underlying <dialog>. Set explicitly to wire up a commandFor trigger.
open boolean false Two-way bindable open state via [(open)].
title string | undefined undefined Optional heading rendered in the modal header.
size 'sm' | 'lg' | 'xl' | undefined undefined Dialog width.
centered boolean false Vertically centers the dialog.
scrollable boolean false Keeps the header/footer fixed and scrolls the body when content overflows.
staticBackdrop boolean false Disables closing via backdrop click or Escape.
dismissible boolean true Shows the header close button.

Outputs

NameTypeDescription
closed OutputEmitterRef<void> Emitted whenever the modal closes, regardless of cause.
