Components / Input Group

Input Group

Wraps a form control with prepended and/or appended text, icons, or buttons. Uses named content slots since prepend/append content is often interactive, not just text.

Text prepend

@ 
<usli-input-group>
  <span usliPrepend class="input-group-text">@</span>
  <input class="form-control" placeholder="username" />
</usli-input-group>

Button append

<usli-input-group>
  <input class="form-control" placeholder="Search" />
  <button usliAppend class="btn btn-usli-primary" type="button">Go</button>
</usli-input-group>

Prepend and append together

$ .00 
<usli-input-group>
  <span usliPrepend class="input-group-text">$</span>
  <input class="form-control" />
  <span usliAppend class="input-group-text">.00</span>
</usli-input-group>
