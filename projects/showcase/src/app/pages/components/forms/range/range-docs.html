Components / Range

Range

A native <input type="range"> slider. Same ControlValueAccessor pattern as usli-input.

Basic usage

<usli-range [formControl]="volume" [showValue]="true"></usli-range>

Custom min/max/step

<usli-range [formControl]="step" [min]="0" [max]="50" [step]="5" [showValue]="true"></usli-range>

Inputs

NameTypeDefaultDescription
min number 0 Minimum value.
max number 100 Maximum value.
step number 1 Step increment.
showValue boolean false Shows the live numeric value next to the slider.
errorMessage string | undefined undefined Explicit error message, shown regardless of control state.
