Placeholder

A loading skeleton — a pure-CSS animated block that stands in for content while it loads. No JavaScript involved.

Basic usage

Set a width to control the skeleton's length. 

<usli-placeholder width="100%" [block]="true"></usli-placeholder>
<usli-placeholder width="75%" [block]="true"></usli-placeholder>
<usli-placeholder width="50%" [block]="true"></usli-placeholder>

Animation

Set animation to 'glow' or 'wave' for a shimmering effect. 

<usli-placeholder width="8rem" animation="glow"></usli-placeholder>
<usli-placeholder width="8rem" animation="wave"></usli-placeholder>

Inputs

NameTypeDefaultDescription
width string | number '100%' CSS width of the skeleton.
size 'xs' | 'sm' | 'lg' | undefined undefined Bootstrap placeholder size.
animation 'glow' | 'wave' | undefined undefined Shimmer animation.
block boolean false Renders as a block-level element so multiple placeholders stack as lines.
