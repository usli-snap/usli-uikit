Tooltip

A pure-CSS tooltip directive — no JavaScript, no positioning library. Plain text only, static placement, no collision detection. For rich content or smart positioning, use Popover instead.

Requires the usli-tooltip global stylesheet to be imported once in your app's styles (a directive has no styleUrl of its own): @use 'ui-sdk/src/lib/usli-tooltip';

Basic usage

Apply usliTooltip to any element with the tooltip text.

Hover me 
<usli-button usliTooltip="Saved to your library">Hover me</usli-button>

Placement

Top Bottom Start End 
<usli-button usliTooltip="Bottom tooltip" tooltipPlacement="bottom">Bottom</usli-button>

Inputs

NameTypeDefaultDescription
usliTooltip string required Tooltip text.
tooltipPlacement 'top' | 'bottom' | 'start' | 'end' 'top' Which side the tooltip renders on.
