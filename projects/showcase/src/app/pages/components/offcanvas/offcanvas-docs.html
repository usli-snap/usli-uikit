Offcanvas

A panel that slides in from an edge of the screen. Built on the same native <dialog> mechanism as Modal — only the placement and slide animation differ.

Basic usage

Open panel Panel content goes here. 
<usli-button commandFor="demo-offcanvas" command="show-modal">Open panel</usli-button>

<usli-offcanvas id="demo-offcanvas" title="Filters">
  Panel content goes here.
</usli-offcanvas>

Placement

End Slides in from the right. Bottom Slides up from the bottom. 
<usli-offcanvas id="demo-offcanvas-end" placement="end" title="From the end">
  Slides in from the right.
</usli-offcanvas>

Inputs

NameTypeDefaultDescription
id string | undefined auto-generated Id of the underlying <dialog>. Set explicitly to wire up a commandFor trigger.
open boolean false Two-way bindable open state via [(open)].
placement 'start' | 'end' | 'top' | 'bottom' 'start' Which edge the panel slides in from.
title string | undefined undefined Optional heading rendered in the panel header.
staticBackdrop boolean false Disables closing via backdrop click or Escape.
dismissible boolean true Shows the header close button.

Outputs

NameTypeDescription
closed OutputEmitterRef<void> Emitted whenever the panel closes, regardless of cause.
