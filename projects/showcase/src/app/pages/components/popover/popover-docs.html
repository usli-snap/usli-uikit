Popover

Rich content on demand, built on the native popover attribute — open/close, light-dismiss, and top-layer stacking all come from the browser. Trigger it with usli-button's Invoker Commands support (command="toggle-popover"). A small script positions it next to the trigger on open; it isn't re-measured on scroll or resize.

Basic usage

Click me This is some popover content with more detail than a tooltip. 
<usli-button commandFor="demo-popover" command="toggle-popover">Click me</usli-button>

<usli-popover id="demo-popover" title="Did you know?">
  This is some popover content with more detail than a tooltip.
</usli-popover>

Inputs

NameTypeDefaultDescription
id string | undefined auto-generated Id of this popover. Set explicitly to wire up a commandFor trigger.
title string | undefined undefined Optional heading rendered above the projected body content.
placement 'top' | 'bottom' | 'start' | 'end' 'top' Static placement hint relative to the trigger — no collision detection.
