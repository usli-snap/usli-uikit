Components / Dropdown

Dropdown

Built on native <details>/<summary> — open/close needs no JavaScript. A small script closes the menu on an outside click, Escape, or item selection, matching what users expect from a dropdown.

Basic usage

Edit Duplicate
Delete 
<usli-dropdown label="Actions">
  <a class="dropdown-item" href="#">Edit</a>
  <a class="dropdown-item" href="#">Duplicate</a>
  <hr class="dropdown-divider" />
  <a class="dropdown-item" href="#">Delete</a>
</usli-dropdown>

Alignment and variant

One Two 
<usli-dropdown label="Right-aligned" variant="primary" align="end">
  <a class="dropdown-item" href="#">One</a>
  <a class="dropdown-item" href="#">Two</a>
</usli-dropdown>

Inputs

NameTypeDefaultDescription
label string 'Dropdown' Trigger button text — used when no content is projected into the toggle.
variant ButtonVariant 'secondary' Trigger button color variant.
align 'start' | 'end' 'start' Menu alignment relative to the trigger.
disabled boolean false Disables the trigger.
