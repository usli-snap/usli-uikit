Toast

A brief, non-blocking notification with an optional auto-dismiss timer. Wrap one or more toasts in your own positioned .toast-container — there's no built-in stacking service.

Basic usage

Your changes have been saved. 
<div class="toast-container position-fixed bottom-0 end-0 p-3">
  <usli-toast title="Notification" [autohide]="false">
    Your changes have been saved.
  </usli-toast>
</div>

Variant and auto-hide

Operation completed successfully. 
<usli-toast variant="success" title="Saved" [delay]="3000">
  Operation completed successfully.
</usli-toast>

Inputs

NameTypeDefaultDescription
variant 'error' | 'warning' | 'info' | 'success' 'info' Semantic color variant.
title string | undefined undefined Optional heading rendered above the projected content.
autohide boolean true Automatically dismisses the toast after delay ms.
delay number 5000 Autohide delay in milliseconds.
dismissible boolean true Shows a close button that hides the toast.

Outputs

NameTypeDescription
dismissed OutputEmitterRef<void> Emitted when the toast hides, whether by timer or the close button.
